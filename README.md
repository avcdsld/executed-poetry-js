# Executed Poetry for JavaScript

Seven code poems that run, held fully onchain as an Ethereum token. Each pairs a
title in plain language with a few lines of JavaScript; the computer takes the
title at its word and executes it. What remains is the signed trace of the run.
Poetry arises in the gap between what is said and what is done.

## The poems

1. Come close enough to stop me.
2. Name it.
3. Know yourself.
4. Remember which way you came.
5. I'm fine.
6. Someone remembers me.
7. Make a promise. Forget how to keep it. Forget how to break it.

## Layout

- `contracts/`: the ERC721 token (`ExecutedPoetry`) and its renderer (`Runtime`)
- `preview/`: rendered mocks
- `vendor/`: the onchain material
